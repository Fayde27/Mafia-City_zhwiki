## 二、各項詳情與排查指引

### 1. JWT 密鑰強制（`src/lib/auth.ts`）
- **改了什麼**：刪除 `process.env.JWT_SECRET || 'your-secret-key...'` 的硬編碼 fallback；缺失時直接 `throw`。
- **為什麼**：原 fallback 一旦被推上線，等於密鑰公開，任何人可偽造管理員登錄 token。
- **⚠️ 出問題時查**：若部署後**全站 500 / 後台無法登錄**，極可能是 Cloudflare Pages **環境變量 `JWT_SECRET` 未配置**。去 Cloudflare Pages 項目設置補上即可。

### 2. 中間件保護 API + role 校驗（`src/middleware.ts`）
- **改了什麼**：matcher 加入 `/api/admin/:path*`；校驗從「token 有效」收緊為 `payload.role === 'admin'`。
- **⚠️ 出問題時查**：若**管理員登錄後仍被踢回登錄頁 / API 全 401**，檢查資料庫 `User` 表該帳號的 `role` 欄位是否確為 `'admin'`（大小寫敏感）。

### 3. 富文本鏈接協議校驗（`src/components/MarkdownRenderer.tsx`）
- **改了什麼**：新增 `safeUrl()`，套在 3 處 `href`/`src`。只放行 `http(s)`/相對路徑/錨點，攔截 `javascript:`/`data:`/`vbscript:`。
- **⚠️ 出問題時查**：若某條**正常鏈接點擊後跳到 `#`（無效）**，說明它被 `safeUrl` 判為危險協議——檢查該 URL 是否以非 `http(s)` 的協議開頭。**注意**：此函數用於 markdown 純文本渲染路徑；HTML 富文本（`dangerouslySetInnerHTML`）分支不經過它。

### 4. 安全響應頭 + CSP（`public/_headers`）
- **改了什麼**：對所有路由加 `X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff`、`Referrer-Policy`、`Permissions-Policy`，以及一條強制生效的 `Content-Security-Policy`。
- **CSP 當前策略**：允許 `'self'` + inline script/style（Next 水合與富文本所需）、`data:`/`https:` 圖片、Supabase 連線；封鎖外部腳本、object/embed、base-uri、frame 嵌套、跨域表單。
- **⚠️ 出問題時查**：
  - 若**頁面某資源加載不出來 / 功能壞掉**，F12 Console 看有無紅色 `Refused to ... because it violates the directive "xxx-src"`。把對應來源加進 `_headers` 裡相應指令的白名單。
  - 常見需放行場景：接入新的第三方圖床 → 加到 `img-src`；接入統計/客服腳本 → 加到 `script-src`（需該域名）。
  - **若要做 iframe 自嵌**（文章嵌文章）：把 `X-Frame-Options: DENY` 改 `SAMEORIGIN`，CSP `frame-ancestors 'none'` 改 `'self'`。
  - 調試 CSP 時可臨時把 `Content-Security-Policy` 改回 `Content-Security-Policy-Report-Only`（只報告不攔截）。

### 5. 錯誤信息脫敏（`upload/route.ts`、`fix-character-types/route.ts`）
- **改了什麼**：錯誤返回改為通用文案（「上傳失敗，請稍後重試」等），原始錯誤轉 `console.error`。
- **⚠️ 出問題時查**：前端只看到通用報錯時，**詳細錯誤在 Cloudflare Pages 的 Functions 日誌**（`console.error` 輸出）裡找。

### 6. 搜索過濾注入修復 + limit 上限（`src/lib/sanitize.ts` 等）
- **改了什麼**：
  - `sanitizeSearch()`：清除搜索詞中 PostgREST `.or()` 的保留字符（`,()"'\\:`），防止注入篡改過濾、繞過 `isPublished`。已套用於 `wiki/articles`、`wiki/characters`。
  - `clampLimit()`：分頁 `limit` 夾在 1~50，防超大 limit 一次性拖庫。套用於 `wiki/articles`。
- **⚠️ 出問題時查**：若**搜索結果異常少 / 搜索含特殊符號的詞無結果**，是 `sanitizeSearch` 把符號替換成空格了——正常現象，非 bug。若要放寬，調整 `src/lib/sanitize.ts` 的正則。

### 7. robots.txt（`public/robots.txt`）
- **改了什麼**：禁止抓取 `/admin/`、`/api/`；封鎖 GPTBot/CCBot/ClaudeBot 等 AI 訓練爬蟲；聲明 Sitemap 地址。
- **⚠️ 出問題時查**：若某搜索引擎不收錄，確認其 User-agent 沒被誤封；搜索引擎爬蟲（Googlebot/Bingbot）只受 `User-agent: *` 規則影響，僅禁了 `/admin /api`，內容頁正常。

### 8. 動態 sitemap（`src/app/sitemap.ts`）
- **改了什麼**：`edge` + `force-dynamic`，請求時遍歷已發布的建築/角色/道具/兵種/裝備/文章 + 靜態頁，生成 `/sitemap.xml`。每個數據源獨立 try/catch。
- **URL 規則**：詳情頁 `/wiki/{類型}/{分類slug}/{內容slug}`；裝備 `/wiki/equipment/{equipType}/{slug}`；文章 `/wiki/article/{slug}`。
- **⚠️ 出問題時查**：
  - 若 sitemap **缺某類內容**，檢查該表記錄 `isPublished` 是否為 true、`slug` 與所屬分類 `slug` 是否為空（兩者缺一該條會被跳過）。
  - 若**新增了內容類型**，需到 `sitemap.ts` 補對應查詢。
  - 域名硬編碼在文件頂部 `BASE` 常量，換域名要改這裡。

### 9. TipTap 重複擴展修復（`src/components/RichTextEditor.tsx`）
- **改了什麼**：`StarterKit.configure({ link: false, underline: false })`，因 StarterKit v3 已內含 link/underline，與下方自訂版本重複（Console 報 `Duplicate extension names`）。
- **⚠️ 出問題時查**：若升級 TipTap 後編輯器鏈接/下劃線功能異常，檢查這裡的停用配置與自訂擴展是否仍匹配新版本。

### 10. 登錄限流（Cloudflare 後台，非代碼）
- **位置**：Cloudflare → 域名 `mafiacity-zhwiki.com` → Security → Security rules → Rate limiting rules。
- **規則 `admin-login-bruteforce`**：同一 IP 對 `/api/admin/login` 10 秒內 >5 次 → Block 10 秒。
- **⚠️ 出問題時查**：若**自己登錄被攔（429/被 block）**，是短時間試錯太多次，等 10 秒即可；或臨時在該規則調高閾值。免費版只能建 1 條速率規則。

### 11. AI 爬蟲攔截 + Bot Fight Mode（Cloudflare 後台，非代碼）
- **位置**：AI Crawl Control → Security（攔截 AI Crawler/AI Search 類）；Security → Bots（Bot Fight Mode 開關）。
- **原則**：只封 AI 爬蟲，**保留** Search Engine Crawler（Googlebot/Bingbot/Baidu）以保 SEO。
- **⚠️ 出問題時查**：若**正規搜索引擎被擋 / 自然流量驟降**，到 AI Crawl Control 確認沒誤封 Search Engine Crawler 類；Bot Fight Mode 偶爾誤傷時可臨時關閉排查。

## 三、主動未做的項（及原因）

- **DOMPurify 富文本清洗**：調研後確認——公開投稿走 React 自動轉義（後台審稿頁用 `{content}` 而非 `dangerouslySetInnerHTML`），富文本僅管理員可寫，**無不可信內容流入** `dangerouslySetInnerHTML`。加 DOMPurify 在 Cloudflare Edge 上需 jsdom（兼容差），且可能誤刪合法樣式，**風險大於收益**，改用 CSP 兜底。
- **CSP nonce（徹底封內聯腳本）**：需中間件注入 nonce，改動大；當前威脅入口已封，列為低優先級可選項。
