# 線下陣容搭配工具

單一 HTML 檔案，可直接分發給運營／外部人員，**打開就能配隊做圖**，不需要登入官網後台。

## 檔案

| 檔案 | 說明 |
|------|------|
| `豪杰搭配组合工具.html` | 工具本體（單檔，含 CSS/JS，無外部依賴） |
| `介入wiki结构说明.txt` | 當初給外部開發的需求說明（歷史文件，僅供參考） |

> ⚠️ 這裡是**版本控制用的主檔**。使用者桌面上的 `桌面\英雄 豪杰搭配工具\` 是分發副本；
> 修改請改本目錄的檔案，再複製一份到桌面／發給其他人。

## 能力

- **☁ 載入線上素材**：用 Supabase anon 公鑰走 REST **只讀**拉取角色池 / 武器 / 戰徽 / 流派 /
  全域配置（風格與加點圖標、標籤、角色標識、頁面標題），以及已發佈的陣容。
  首次打開（本機無存檔）會自動載入，做到開箱即用。
- **📤 快速上傳**：圖片直傳 Supabase Storage 桶 `tool-uploads`（匿名 INSERT 策略），
  自動把公開 URL 填回輸入框，不必再去別處找圖片連結。
- **資料存檔**：資料存在瀏覽器 localStorage，可下載／上傳 JSON 存檔在不同機器間搬移，
  或交回官網由後台錄入。

## 前置設定（Supabase，各執行一次）

| SQL | 作用 |
|-----|------|
| `supabase-migrations/2026-07-lineup-restructure.sql` | 建陣容相關表；建 `tool-uploads` 桶並開放匿名上傳 |
| `supabase-migrations/2026-07-hero-lineup.sql` | 英雄配隊相關表（戰寵／英雄裝備／套裝／詞條） |
| `supabase-migrations/2026-07-tool-readonly-access.sql` | 開啟 RLS 並**只放行 anon SELECT**，讓本工具能讀素材；同時堵住「RLS 關閉時 anon 可寫」的隱患 |

未執行第 3 項時，點「載入線上素材」會失敗並提示原因。

## 主題

淺色（白底黑字），字體統一微軟雅黑，不依賴外部字型 CDN。

## 已知落差（與官網）

- 官網已把**詞條與武器/戰徽解綁**（改為配隊時按槽位挑選）；本工具的詞條仍掛在武器上，
  因此線上匯入的武器不帶詞條，做圖需要時在工具內自行補填。
